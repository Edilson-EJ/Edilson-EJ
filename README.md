## Sobre mim

Desenvolvedor de software com mais de 3 anos de experiência prática em desenvolvimento back-end e full stack. Meu foco é a construção e evolução de aplicações com **C# e .NET**, com experiência em **APIs REST, integrações entre sistemas e bancos de dados relacionais**.
